An AI based Receptionist, currently targeting the restaurants domain.
User can have conversation with agent, the agent, adhering to the guidelines, provides response to the customer.
Agent can be commanded to place the order.
The order, after confirmation, will be placed by AI and will be reflected in customer's current orders list.
An Admin View is also implemented where the person (Generally Restaurant Representative) will see the placed order and can change the status of the order and user will be notified accordingly
